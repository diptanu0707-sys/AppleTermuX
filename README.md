# 🍎 AppleTermuX

> Premium Apple-style customization for Termux on Android.

---

## ✨ Features

- 🍎 Beautiful Apple-inspired interface
- ⚡ One-command installer
- 🎨 Powerlevel10k prompt
- 🖥️ Fastfetch system information
- 🚀 Optimized for Termux
- 📦 Automatic package installation
- 🔧 Easy customization
- 💯 Open Source

---

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/diptanu0707-sys/AppleTermuX.git
```

Go to the project directory:

```bash
cd AppleTermuX
```

Run the installer:

```bash
bash install.sh
```
